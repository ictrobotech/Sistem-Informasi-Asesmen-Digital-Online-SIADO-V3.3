Stimulus Gambar (opsional)

Gambar tersimpan rapi di Google Drive pada folder APLIKASI WEB › OUTPUT › GAMBAR dan otomatis dibuka aksesnya. Tidak perlu menempel link.

Format apa pun diterima: /file/d/..., ?id=..., atau link berbagi. Sistem mengubahnya menjadi link tampil otomatis.

Wajib HTTPS agar tidak diblokir browser.

Stimulus Video (opsional)

Maksimal 1 GB, disarankan HD landscape 16:9 (1280×720 atau 1920×1080). Video tersimpan di folder APLIKASI WEB › OUTPUT › VIDEO, diunggah langsung ke Drive dengan progres di bawah.

Video Drive diputar memakai pemutar Drive resmi agar lancar dan tidak memakan kuota aplikasi.

Mendukung file MP4/WEBM langsung maupun YouTube.

Catatan format: PG memilih satu jawaban; PGK menilai setiap pernyataan Benar/Salah; PGK MCMA dapat memiliki lebih dari satu jawaban benar.

Import Soal

Import massal dari file CSV atau Excel (.xlsx). Kolom wajib: tipe, pertanyaan, kunci_jawaban. Kolom opsional: opsi, poin, aktif, mapel, stimulus_gambar, stimulus_video.

Export Laporan Nilai & Pelanggaran

Laporan berisi dua lembar: Nilai (benar, salah, skor, KKM, status Tuntas/Remedial) dan Pelanggaran selama ujian. Format sudah dirapikan dan siap dicetak.

Microsoft Excel

Format .xlsx dengan header berwarna, kolom otomatis, dan ringkasan tuntas/remedial.

Dokumen PDF

Format A4 landscape, rapi untuk ditandatangani dan diarsipkan sekolah.

Saran: nilai seluruh jawaban uraian pada menu Nilai Uraian terlebih dahulu agar kolom status pada laporan tidak berisi "Menunggu Penilaian".

Rombongan Belajar (VII – IX)

Setiap rombel memiliki token ujian sendiri. Peserta login memakai username yang didaftarkan dan token rombel sebagai password. Urutan rombel (VII KH Dewantara, Ahmad Dahlan, ... IX Karanjalemba) diatur oleh admin lewat tombol panah pada kartu rombel di bawah — berlaku di Data Peserta, Monitor, Hasil, Nilai Uraian, Pelanggaran, Rekap Kelas, dan Export.

Bagikan token ini kepada peserta rombel tersebut saat ujian dimulai.
